# 渲染、相机与特效设计

> 结论：后处理和特效的数值从参考作品起步（ACES + HDR RGBA16F + MSAA + 轻 Bloom + 暗角 + 调色 + 动态天空 + 镜头光晕 + 体积雾），湿路面靠"光泽贴图 + 雨纹法线 + 平面反射"三件套。我们相对参考作品补三处：**画质档真正控制阴影/反射/草地/雾**（参考作品只改分辨率）、**加一套电影/拍照相机**（参考作品宣传片的特写和航拍镜头在代码里不存在）、**兰博基尼专属车灯与车漆**。

原始数值与技术细节：`docs/research/rendering.md`（下文用 §x 指它的章节）（该文档只在本地，不在公开仓库里）。

## 2. 设备与应用

- `createGraphicsDevice(canvas, { deviceTypes: ['webgpu', 'webgl2'], antialias: false })`；抗锯齿放在 CameraFrame 的 MSAA 里做。
- 用 `AppBase` 按需注册组件：Render、Camera、Light、ParticleSystem、Script；资源处理器 Texture、Container（加 Json、Audio 视需要）。不注册物理、动画、Element。
- Draco 解码器通过 `WasmModule.setConfig('DracoDecoderModule', …)` 配置，WASM 放 `public/assets/wasm/draco/`。
- 加载流程分阶段汇报进度（文案自拟），最后做着色器预热：开启所有隐藏特效、像素比降到 0.25、强制 boost/surge/漂移/擦墙状态渲染约 20 帧，再恢复（参考 §1.3）。

## 3. 画质档（我们的定义）

| 项 | Low | Normal | High | Ultra |
| --- | --- | --- | --- | --- |
| 像素比上限 | 1 | 1 | 1.5 | 2 |
| MSAA | 1 | 2 | 4 | 4 |
| 阳光阴影贴图 / 级联 / 距离 | 1024 / 1 / 120 m | 2048 / 2 / 200 m | 2048 / 2 / 240 m | 4096 / 3 / 300 m |
| 路面平面反射 | 关 | 0.3× | 0.4× | 0.5× |
| 体积雾 steps / scale | 关 | 关 | 5 / 0.25 | 8 / 0.35 |
| 草密度 / 距离 | 120 / 120 m | 220 / 180 m | 380 / 240 m | 380 / 300 m |
| 镜头水滴、速度模糊 | 关 | 开 | 开 | 开 |
| 动态云 | 关 | 低 | 中 | 高 |

默认档：URL 的 `?q=` 优先，其次是上次在菜单里选的（存在 `localStorage`），都没有时触屏设备用 Low、其余用 Normal。档位在主菜单里切换，下次进入游戏时生效。

M3 的调整（2026-11-26，实测见 `docs/verification/M3/README.md`）：

- 像素比上限就是表里的值与 `devicePixelRatio` 的较小者，代码里不再额外乘系数。Low 从 0.75 改成 1（0.75 在手机上只有 633×292，明显是马赛克）。
- Normal 关掉体积雾（省一个全屏通道，画面差别很小）。
- 曝光不再用测光式自动曝光，改成按"车在防雪走廊里的程度"直接算：`曝光 = 基准 × 2^(tunnelEv × 隧道系数)`，进暗处快、回亮处慢（`POST.exposure.mode = 'tunnel'`；`'auto'` 仍可切回测光式）。
- 加载末尾有 12 帧着色器预热：特效全开，所有相机关闭视锥剔除，让场景里每种材质都画一次。`?nowarm` 跳过。

## 4. 后处理（CameraFrame）起步配置

| 设置 | 值 | 说明 |
| --- | --- | --- |
| `rendering.toneMapping` | ACES | 参考作品同 |
| `rendering.renderFormats` | `[RGBA16F]` | 不可用时引擎回退 RGBA8（Bloom 会关） |
| `rendering.sharpness` | 0.2 | CAS 锐化 |
| `taa` / `ssao` / `dof` | 关 / 关 / 关 | 电影相机模式下开 DOF |
| `bloom.intensity` | 0.022，喷氮气 ×(1 + 0.5·boost + kick) | — |
| `vignette` | 强度 0.35（喷氮气 +0.12），inner 0.45，outer 1.15 | — |
| `grading` | 饱和度 1.06，对比度 1.03 | 兰博基尼版可试暖一点的色调 |
| `fringing`（色散） | 0，喷氮气时 `boost·20 + kick·26` | — |
| 自动曝光 | EV 0–0.7，补偿 −1.2，亮→暗 1.2、暗→亮 2.5 | 进出隧道自动适应 |
| 体积雾 | 密度 4e-4，强度 0.6，高度衰减 0.02，各向异性 0.75，最远 260 m；隧道附近开局部聚光灯散射 | — |
| 动态天空 | 太阳仰角 11°、方位 82°，强度 3.4，浑浊度 2.2，体积云覆盖 0.24，霾高度 200 m；补丁：太阳圆盘亮度钳到 1500 防止 fp16 溢出 | 时间与天气见 `track-and-world.md` |
| 镜头光晕 | 只给太阳：glow_soft 0.2 / burst_star 1.1 / anamorphic_streak 0.08×18 / halo 0.5，总强度 0.3 | 用引擎自带形状贴图（MIT） |

合成顺序（同一个全屏 pass）：scene 槽 = 色散 → CAS → 速度模糊 → 镜头水滴；HDR 槽 = Bloom → 调色 → 镜头光晕；ACES；LDR 槽 = 暗角。

## 5. 自定义后处理（自己实现，参考 §4 的技术思路）

| 特效 | 技术 | 关键参数 |
| --- | --- | --- |
| `speedBlur` | `CameraFrameEffect`，slot `scene`，需深度。相机运动重投影模糊（1/200 s 虚拟快门，最长 3% 屏宽）+ 径向缩放模糊 + 110 道速度线；车身包围盒内不模糊 | amount = `boost·0.11 + kick·0.08 + 开场·0.07`；streaks = `v²·0.05 + boost·0.16 + kick·0.12` |
| `droplets` | slot `scene`。两层静态水珠 + 屏幕两侧下滑水痕，按高度场折射并偏冷色；隧道里逐渐变干 | amount 0.6 + 0.4·速度，进隧道 → 0 |

两者都必须同时写 GLSL 和 WGSL，WGSL 里注意 V 方向翻转。

## 6. 湿路面

1. 漫反射：程序化沥青 2048²（行车线变暗、污渍、裂缝、边线和虚线）+ overlay 细节噪声。
2. 光泽贴图：fbm，光泽 0.42–0.98，形成"有的地方湿、有的地方半干"的斑块。
3. 法线：基础法线 + **动画雨纹法线**（24 帧 256² 法线环，1.1 s 循环，平铺 9×12，凹凸 0.4）。
4. 平面反射：镜像相机（只渲染 World + Skybox 层），HDR，高斯 mip；路面材质按 `(1 − gloss)` 选 mip，粗糙处反射更糊。反射平面跟随车辆所在路面高度与法线。
5. 低档位关掉平面反射，只靠环境图反射。

## 7. 图层与灯光分区

| 图层 | 内容 |
| --- | --- |
| World | 车身、护栏、路肩、广告板、指示牌、地形、拾取物 |

## 10. 车辆渲染（兰博基尼）

- 车漆：按材质名覆盖，`clearCoat 1`、`clearCoatGloss 0.97`，底漆光泽约 0.6；默认色建议 Arancio（橙）或 Verde Mantis（绿），菜单可换色。
- 环境反射：车身单独用一张程序化等距柱状环境图（暖色地平线 → 冷色天顶，地平线下一圈彩色条纹模拟广告板倒影），其余物体用动态天空烘焙的 `envAtlas`。注意参考作品这张图的 RGBP 编码会解码成 1/8 亮度，我们实现时要实测确认。
- 隐藏模型自带的"清漆外壳"类网格（用材质的 clearCoat 代替）。
- 玻璃：不透明度 0.55–0.9，关闭 `opacityFadesSpecular`，保留满强度反射。
- 车灯：Huracán 的 Y 形日行灯和尾灯做成独立自发光材质，平时就亮（参考作品只在隧道附近开灯）；刹车时尾灯自发光 ×5；隧道内开近光（照 World + Road）和远光（只照 Road）。
- 车身动态：悬挂、侧倾、点头三个弹簧（参数见 `vehicle.md` §2.5），漂移时前轮显示反打角 `clamp(−β, ±30°)`。
- 影子：级联阴影 + 车底模糊阴影片（3.3 × 6.1 m，按离地高度变淡）。
- 合批：同一刚体框架、同材质的不透明子网格合并，减少 draw call。
